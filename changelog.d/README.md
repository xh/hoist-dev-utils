# Changelog fragments

Do not edit `CHANGELOG.md` directly. Each pull request adds its entries in a new markdown file
in this folder, and a release assembles them into `CHANGELOG.md`.

Add a one-line entry with `pnpm changelog add <section> "<text>"`.
Entry conventions are in the "Changelog" section of [`CLAUDE.md`](../CLAUDE.md).

See [Changelog fragments](../README.md#changelog-fragments) in the README for the fragment format
and all commands.
